# List of configuration settings

The configuration settings are set up in `ps_configuration` by default when installing PrestaShop.
The list can be found in the xml file [install-dev/data/xml/configuration.xml](https://github.com/PrestaShop/PrestaShop/blob/9.1.x/install-dev/data/xml/configuration.xml)
