## Call of the Hook in the origin file

```php
Hook::exec(
            'adaptImageLink',
            [
                'protocol_content' => $this->protocol_content,
                'uri_path' => $uriPath,
                'url' => &$url,
                'name' => $name,
                'ids' => $idImage,
                'type' => $type,
                'extension' => $extension,
            ]
        );
```
